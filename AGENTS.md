# Инструкции для агентов

## Расширение конфигурации

При добавлении или переименовании полей конфигурации обновляйте весь контракт:

1. Добавьте поле и рабочее значение по умолчанию в `config.example.yaml`.
2. Прочитайте, провалидируйте и верните поле в `scripts/lib/config.js`.
3. Передайте поле в потребителя и покройте валидное и невалидное значения тестами.
4. Обновите README и changeset, если поле относится к пользовательскому интерфейсу конфигурации.
5. Синхронизируйте новое поле в локальном `~/.config/openwrtctl/config.yaml`, потому что `openwrtctl init` сохраняет существующий файл без изменений.

Локальный конфиг не входит в Git. Сохраняйте его пользовательские значения и права `0600`; меняйте только добавленные или явно запрошенные поля. Не создавайте альтернативный `~/.config/openwrt/config.yaml`.

После изменений проверьте загрузку `config.example.yaml` и локального конфига через `scripts/lib/config.js`, затем выполните `npm test` и `git diff --check`. Не выводите в лог весь локальный конфиг.
